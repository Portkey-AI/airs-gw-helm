{{- if (.Values.gatewayApi.gateway | default dict).create }}

The address is assigned once the Gateway controller has provisioned it:

  kubectl get gateway --namespace {{ (.Values.gatewayApi.gateway | default dict).namespace | default .Release.Namespace }} \
    {{ include "gatewayApi.gatewayName" . }} \
    -o jsonpath='{.status.addresses[0].value}'
{{- else }}

The HTTPRoutes attach to a Gateway managed outside this chart. Verify they were
accepted by their parent Gateway:

  kubectl get httproute --namespace {{ .Release.Namespace }} \
    -l app.kubernetes.io/instance={{ .Release.Name }} \
    -o wide
{{- end }}

{{- else if eq .Values.service.type "LoadBalancer" }}

Gateway is exposed via a LoadBalancer service. It may take a few minutes for the external IP to be assigned.

  kubectl get svc --namespace {{ .Release.Namespace }} {{ include "airsgateway.fullname" . }} \
    -w -o jsonpath='{.status.loadBalancer.ingress[0].ip}'

Once assigned:
  http://<EXTERNAL-IP>:{{ .Values.service.port }}/v1/health

{{- else }}

Gateway is not exposed externally. To access it locally:

  kubectl port-forward --namespace {{ .Release.Namespace }} \
    svc/{{ include "airsgateway.fullname" . }} \
    {{ .Values.service.port }}:{{ .Values.service.port }}

  http://127.0.0.1:{{ .Values.service.port }}/v1/health

To expose externally, set service.type=LoadBalancer, ingress.enabled=true with ingress.hostname, or gatewayApi.enabled=true with gatewayApi.hostname.
{{- end }}
